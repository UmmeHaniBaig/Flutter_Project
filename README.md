# Food_App (Flutter)

A simple food ordering demo UI built with core Flutter layout widgets —
no external UI packages.

## Pages
1. **Login** (`lib/login_screen.dart`) — email + password fields
2. **Signup** (`lib/signup_screen.dart`) — name + email + password fields
3. **Home** (`lib/home_screen.dart`) — static food list with images
4. **Cart** (`lib/cart_screen.dart`) — shared cart list, remove items
5. **Profile** (`lib/UserProfile_card.dart`) — user info + stats

## Run it
```bash
flutter pub get
flutter run
```
